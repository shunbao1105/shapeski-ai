# ShapeSki AI 🎿

AI-powered skiing and snowboarding motion analysis platform.

**Live Demo:** https://shunbao1105.github.io/shapeski-ai/

## Features

- 🤖 **TensorFlow.js MoveNet** — Real browser-based AI pose detection (17 keypoints)
- 🎿 **Ski & Snowboard** — Dual mode analysis
- 📱 **Mobile friendly** — Works on phone browsers
- 💳 **Payment ready** — WeChat Pay QR code integration
- 🔒 **Privacy first** — All processing happens locally, no server needed
- 🎁 **Free trial** — 1 free analysis per user
